explicit reviewed cross-repository runtime-evidence acceptance authority

## Internal prerequisite findings/tranches

- T29 source/lifecycle/manifest/child/acceptance graph accepted or SOURCE_COMPLETE_EXTERNAL_PENDING
- T35 managed long-soak proof accepted
- T36 immutable preflight/environment/recovery/promotion graph accepted or SOURCE_COMPLETE_EXTERNAL_PENDING

## Required environment receipts

- real provider-to-PostgreSQL-to-API parity receipt
- accepted private PostgreSQL and runtime environment identity
- production-entrypoint source/lifecycle/evidence receipts

## External prerequisites

- accepted read-only upstream handoff
- authorized contract-compatible downstream read-only API resource
- real provider lineage and parity

## Required immutable generation graph

- source_generation
- config_generation
- process_generation
- evidence_generation
- test_generation
- environment_generation
- tranche_generation for T29/T35/T36
- campaign_generation

Every node must name exact parent generations, content digests, clock authority, owner/reviewer, and retained holds. A mutable status document or latest pointer is not sufficient.

## Accepted evidence classes

- schema-valid immutable receipts from the required source, configuration, process, evidence, release, test, environment, tranche, and campaign generations;
- executed production-entrypoint and environment proof bound to the exact accepted postimage;
- independently verifiable external authority where this hold requires it;
- explicit hold-release decision from the decision owner.

## Rejected evidence and prohibited substitutions

- fixture
- mock
- local export
- placeholder
- synthesized schedule
- BWS local API
- dashboard route
- caller assertion
- documentation
- source-only completion
- static validator

## Conditions that still retain the hold

- accepted handoff absent
- parity missing or synthetic
- T29/T35/T36 proof missing/stale/wrong-generation
- runtime target/config/clock/lineage unresolved
- any internal finding remains open

## Binding rule

Documentation, a source postimage, a static validator, a test list, or source completion alone does not release `BWS-600`. `SOURCE_COMPLETE_EXTERNAL_PENDING` retains the hold. Unknown, missing, stale, wrong-generation, caller-asserted, or synthetic evidence retains the hold.
