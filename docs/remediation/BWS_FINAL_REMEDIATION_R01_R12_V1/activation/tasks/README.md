# Exact tranche task sources

There is one task source for every campaign order. Each file carries one tranche identity, exact dependency set, exact test counts, one protected-file policy, one result path, and no authority to work on another tranche.

Orders 1 through 13 are direct bounded Codex tasks. Orders 14 through 47 may be passed to the repaired implementation controller only after the S2 gate verifier succeeds.
