
# S0 authority-conflict checklist

Stop and record `BLOCKED` when any conflict exists:

- current source contradicts a finding, symbol, path, or correction boundary;
- campaign-map identity, finding membership, owner, dependency, stage, or acceptance authority differs;
- architecture sequencing conflicts with machine membership;
- protected task, queue, controller, hold, release, or deployment authority changed without explicit authorization;
- a dependency lacks an accepted predecessor postimage;
- the exact Node/runtime or required proof environment cannot be established;
- source-manifest drift is treated as a pass or a validator is weakened;
- an external requirement is replaced with a fixture, mock, local export, declaration, or caller assertion;
- any path outside the exact admission boundary would need mutation;
- any source, runtime, service, database, credential, or documentation belonging to `betting-win` would be accessed or mutated.

Conflicts are recorded. They are never silently reconciled.
