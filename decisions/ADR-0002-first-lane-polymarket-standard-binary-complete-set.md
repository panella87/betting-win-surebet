# ADR-0002 - Initial standard-binary complete-set lane

## Status

Accepted for the initial safe-local lane. Later BWS-700 authority explicitly extended research and deterministic offline/private-paper falsification to B1 cross-venue work without replacing this same-venue decision.

## Decision

The initial lane is same-venue standard-binary complete-set analysis using the betting-win `surebet_standard_binary_v0` profile. Provider-specific labels never replace identity, rule, or scenario equivalence.

## Consequences

The initial safe-local program excluded cross-venue, back/lay, synthetic equivalence, market making, routing, and execution unless a later validated task added them. `BWS-700` subsequently authorized B1 cross-venue offline falsification through dependency-ready local rows, while `BWS-710` remains blocked on an accepted `betting-win.b1_multi_venue_markets.v1` resource. Provider access and execution remain prohibited.
